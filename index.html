About Pokédex

Welcome to this interactive Pokédex - a comprehensive guide to your favorite Pokémon!

Features:

  • 🔍 Search Pokémon by name or ID
  • 🎲 Discover random Pokémon
  • ❤️ Save your favorites locally
  • 📊 View detailed stats and types
  • 📱 Fully responsive design
Data Source: This app uses the PokéAPI - a free, easy-to-use API for Pokémon data. Built with ❤️ for Pokémon fans and aspiring developers!
